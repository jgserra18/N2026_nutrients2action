# N2026: From Nutrient Metrics to Action

Static session page for GitHub Pages.

## Add the position papers

Export each approved paper to PDF and add it to `papers/` using these numbered filenames:

```text
papers/00_background.pdf
papers/01_vos.pdf
papers/02_baris.pdf
papers/03_oita.pdf
papers/04_serra.pdf
papers/05_baisden.pdf
papers/06_winiwarter.pdf
papers/07_quemada.pdf
papers/08_su.pdf
papers/09_graversgaard.pdf
```

The number controls the display order. The page currently links to these filenames, so use them as written or update the corresponding `href` in `index.html`. The website contains only the short listing and key claim; the PDF remains the full paper.

The Mentimeter callout is included as `assets/mentimeter_callout.png`; keep that path when adding the files to GitHub, because the page references it directly.

Before publishing, replace the provisional programme text with the confirmed date, time, room, and convenors. Check that every PDF link works and that contributors have agreed to public distribution.

## Publish with GitHub Pages

1. Add `index.html`, this README, and the `papers/` folder to the repository root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. GitHub will show the published site URL in the Pages settings after deployment.
